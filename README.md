# Quick Cords

A simple Fabric client mod that copies your current coordinates to the clipboard. Press C in-game to copy your block position as `x y z`, then paste it in chat, Discord, or a command. An action-bar message shows what was copied.

The default key is C. To change it, open Options → Controls → Key Binds, find the Quick Cords category, and click Copy Coordinates. Press the key you want. It uses Minecraft's normal keybind menu, so the new bind is saved with the rest of your controls.

Needs Fabric Loader and Fabric API. Built for 1.20.4, 1.21.8, 1.21.11, and 26.1.
